## 🎯 Мета роботи
- Спроєктувати та реалізувати шар бізнес-логіки (Business Logic Layer, BLL) для платформи рольової гри та каталогу персонажів відповідно до принципів Clean Architecture.
- Імплементувати детерміновані математичні моделі розрахунку фізичного та магічного бою:
  - **Фізична атака:**
    $$dmg_{phys} = \max(0, dmg_{flat} - armor_{tgt}) \times \max(0, 1 - \max(0, res_{tgt} - res_{pen}))$$
  - **Магічна атака / використання вмінь:**
    $$dmg_{magic} = \left( dmg_{flat} \times \max(0, 1 - res_{tgt} + res_{pen}) + bonus_{flat} \right) \times \max(0.1, 1 + bonus_{prof} - debuff_{ability})$$
    де $bonus_{flat} = \sum(bonus_{item} + bonus_{skill} + bonus_{buff})$.
- Розробити покроковий бойовий рушій (`TurnBasedBattleEngine`):
  - Динамічний таймлайн на основі показника швидкості (`Speed`).
  - Перевага за швидкістю: якщо найшвидший боєць перевершує найповільнішого за швидкістю у $\ge 1.5$ раза, він отримує додатковий слот дії в раунді.
  - Покроковий життєвий цикл бою: тік статусів, обробка DoT (Damage over Time), перевірка оглушення (`Stun`), вибір дії, розрахунок шкоди та протоколювання.
- Створити підсистему статус-ефектів (`StatusEffect`): Buff, Debuff, DamageOverTime, Stun із контролем тривалості в раундах.
- Впровадити шар представлення даних через ViewModel (`CharacterProfileViewModel`): ізоляція доменних сутностей від CLI/GUI, форматування зірочок рідкісності (`★★★★★`), елементів та URL аватарок.
- Скласти детальний дизайн-документ ([DESIGN.md](file:///d:/Project/lerning/pk14biz/DESIGN.md)).
- Забезпечити повне покриття функціоналу модульним тестуванням на базі xUnit.

## 🧮 Математична модель бойової системи

### 1. Фізична атака
Враховує базову броню цілі, бонуси броні від екіпірованих предметів та активних бафів/дебафів, а також пробиття опору:
$$dmg_{phys} = \max(0, dmg_{flat} - armor_{tgt}) \times \max(0, 1 - \max(0, res_{tgt} - res_{pen}))$$
У разі критичного удару:
$$dmg_{final} = dmg_{phys} \times CritMultiplier$$

### 2. Магічна атака
Враховує адитивні бонуси предметів і пасивок, коефіцієнт майстерності атакуючого та дебафи на заклинання з гарантованим мінімальним порогом ефективності ($0.1$):
$$dmg_{magic} = \left( dmg_{flat} \times \max(0, 1 - res_{tgt} + res_{pen}) + bonus_{flat} \right) \times \max(0.1, 1 + bonus_{prof} - debuff_{ability})$$

## ⚡ Покроковий рушій бою (Turn-Based Battle Engine)

1. **Ініціалізація раунду:** обчислюються ефективні швидкості бійців з урахуванням екіпіровки та статусів.
2. **Черга ходів:** бійці впорядковуються за спаданням швидкості. Якщо $\frac{Speed_{max}}{Speed_{min}} \ge 1.5$, найшвидший учасник отримує додатковий хід.
3. **Обробка початку ходу (`TickStatusEffects`):**
   - Шкода від ефектів DoT (горіння, отрута) наноситься безпосередньо по здоров'ю.
   - Тривалість ефектів зменшується на 1, вичерпані ефекти видаляються.
   - Якщо боєць має активний ефект оглушення (`Stun`), хід пропускається (`TurnActionType.Skip`).
4. **Виконання дії:** розрахунок через `CombatCalculator`, нанесення шкоди/лікування, накладання нових статусів від умінь.
5. **Фіксація результатів:** створення об'єкта `Turn` і додавання до `BattleHistory`.
